## Start with the use case

Before choosing between Mistral AI and other services, write down the task, data types, budget, security requirements and integrations you need.

## A reusable comparison framework

| Criterion | Question to document |
| --- | --- |
| Quality | Are results correct for your own test cases? |
| Governance | Where does data flow, and which commitments are contractual? |
| Integration | Does the tool fit your systems and processes? |
| Cost | What is the total cost at your expected volume? |
| Accessibility | Does the experience work well in FR-CA and EN-CA? |
| Operations | Which monitoring, evaluation and audit options are available? |

## Publish a trustworthy field report

State the parameters, test date, limitations, criteria and risks. Do not generalize from one isolated result. When feasible, include a reproducible example **without personal information or secrets**.
