## Suggest content or a meetup

1. Prepare a contribution and open a [Pull Request on GitHub](https://github.com/mistralboreal/mistralboreal.github.io/pulls).
2. Identify the contribution type: article, training, demonstration or meetup.
3. Describe the intended audience and goals, and for comparisons, the criteria used.
4. Supply Canadian French (FR-CA) and Canadian English (EN-CA) versions, or request translation support.

## Contribute directly to the site

The repository is public: [Mistral Boreal on GitHub](https://github.com/mistralboreal/mistralboreal.github.io). Content lives in **knowledge/okf**. Each editorial contribution needs matching FR-CA and EN-CA entries with the same translation key. See the repository README and editorial guide.

## Participation guidelines

Prioritize transparency and respect. Never disclose personal data, corporate secrets or API keys. Official external resources must be attributed and linked, not copied without permission.
