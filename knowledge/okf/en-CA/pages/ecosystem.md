## Information from official sources

This is an **independent summary** of Mistral AI products, with links to their own documentation. **Mistral Boreal is not an official Mistral AI community**, and linking to these resources does not imply endorsement or partnership.

Features, access conditions and pricing can change. Always check Mistral AI’s websites for current details.

## Vibe: conversations, work and code

Mistral evolved **Le Chat into Vibe**, its unified AI experience. Its documentation identifies two complementary use cases:

- **Vibe Work** for conversations, research, summaries and multi-step professional work across web and mobile.
- **Vibe Code** for understanding repositories, editing code, running commands and preparing pull requests under human supervision.

Many members still recognize the Le Chat name. We now prioritize Mistral AI’s current **Vibe Work / Vibe Code** terminology.

**Official sources:** [Vibe overview](https://docs.mistral.ai/vibe), [Vibe Code overview](https://docs.mistral.ai/vibe/code/overview), [Le Chat becomes Vibe — Mistral Help Center](https://help.mistral.ai/fr/articles/682992-le-chat-devient-vibe).

## Studio and the Mistral API

**Studio** is the developer environment for API keys, experiments in the Playground, models, agents, evaluations and usage monitoring. Organizations can select tools based on business requirements, data obligations, cost and integration.

**Official sources:** [Studio overview](https://docs.mistral.ai/studio), [first API request](https://docs.mistral.ai/getting-started/quickstarts/developer/first-api-request).

## Models and informed technology choices

Mistral AI offers multiple models and capabilities for language, code, multimodal workloads and specialized services. We recommend reading the current catalogue rather than relying on a fixed list and **testing alternatives against your own use cases**.

**Official sources:** [model catalogue](https://docs.mistral.ai/models), [platform overview](https://docs.mistral.ai/getting-started/platform-overview), [Mistral AI website](https://mistral.ai/).
