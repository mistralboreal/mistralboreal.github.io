## Before you start

Read the [official first API request guide](https://docs.mistral.ai/getting-started/quickstarts/developer/first-api-request). You will need a developer account and, depending on the service and access mode, an API key.

## Activity

1. Read the official instructions and choose Python or TypeScript.
2. Create a development key according to the security guidance.
3. Keep the key in an environment variable, never in Git.
4. Run an example from the official source, then change the prompt to a real use case.
5. Record your results and the limits of your test.

## Precautions

Never include **API keys, confidential data or personal information** in a repository or public example. Check usage terms and pricing before running experiments.
